# Distributed KV Store

A key-value store built from scratch in C++.

The project will progressively evolve from a simple single-node
in-memory store into a distributed key-value database.

## Current Features

- In-memory key-value storage
- SET operation
- GET operation
- DELETE operation
- Unit tests

## Tech Stack

- C++
- CMake
- Git

## Roadmap

- [x] Single-node KV store
- [x] Unit testing with GoogleTest
- [ ] TCP server
- [ ] Concurrent clients
- [ ] Write-ahead logging
- [ ] Crash recovery
- [ ] Storage engine
- [ ] Multi-node cluster
- [ ] Replication
